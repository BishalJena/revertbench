    How the benchmark works
    
        
    These replays show recorded checks against real bugs. Comparative AI model results are pending.
    
      
    
      
      
        
    1. 
          
      Recover a real regression
      
          
      Keep the code before a change, the buggy version, and the buggy version with its repair applied. Check that a historical reference test passes, fails, then passes.
      
        
      2. 
        
    2. 
          
      Give the model the change
      
          
      Ask the model to write a test as if it were reviewing the original pull request. Keep the repair and the reference test hidden.
      
        
      3. 
        
    3. 
          
      Score the test on both versions
      
          
      Run it against the bug and the repair in isolated Docker containers. A valid test fails for the expected reason on the bug and passes with the repair across repeats.
