How it works

RevertBench checks whether a test can tell buggy code from fixed code.

  1. Start with a real bug

    Find an update that broke something and the later fix. Confirm that a historical test catches the bug and passes with the fix.

  2. Ask the AI to write a test

    Give the AI the original code change. Hold back the fix and the historical test.

  3. Run the same test on both versions

    To earn credit, the test must reach the changed code, fail because of the bug, and pass with the fix across repeated runs.
